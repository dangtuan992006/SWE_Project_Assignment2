# Ma trận truy vết yêu cầu (Traceability Matrix)

### 1. Quy ước định danh sơ đồ và tài liệu thiết kế

- **UseCase-01:** Sơ đồ use-case tổng quát (`docs/diagrams/usecase-overview.puml`)
- **Activity-01:** Sơ đồ hoạt động luồng đặt món & thanh toán (`docs/diagrams/activity-checkout.puml`)
- **Sequence-01:** Sơ đồ tuần tự luồng checkout trọng tâm (`docs/diagrams/sequence-checkout.puml`)
- **Class-01:** Sơ đồ lớp miền domain model (`docs/diagrams/class-domain.puml`, `docs/diagrams/class-domain.md`)
- **Deployment-01:** Sơ đồ triển khai production (`docs/diagrams/deployment.puml`, `docs/deployment.md`)
- **Architecture-01:** Tài liệu thiết kế kiến trúc hệ thống (`docs/architecture/README.md`)

### 2. Quy ước mã kiểm thử (Test Conventions)

- **UNIT-\*:** Unit Test kiểm thử logic nghiệp vụ nội bộ các Service (`apps/api/src/**/*.spec.ts`)
- **API-\*:** Controller / Endpoint Test kiểm thử hợp đồng API HTTP & RBAC (`*.controller.spec.ts`)
- **INT-\*:** Integration Test kiểm thử tương tác Database, Transaction, Optimistic Locking, State Machine & Cổng thanh toán (`orders.service.spec.ts`, `payments/*.spec.ts`)
- **E2E-\*:** End-to-End Test luồng nghiệp vụ hoàn chỉnh (`apps/api/test/app.e2e-spec.ts`, `tests/e2e-checkout.flow.mjs`, `tests/e2e-integration.spec.ts`)
- **UI-PAY-\* / UI-BUILD-\*:** Kiểm thử logic thanh toán/đối soát phía Client (`apps/web/tests/vnpay-payment.test.mjs`) và kiểm tra static lint/build Next.js (`apps/web`: `npm run lint`, `npm run build`)
- **SEC-\*:** Security Test kiểm thử phân quyền Role (`roles.guard.spec.ts`), sở hữu tài nguyên và Hashing mật khẩu `bcrypt`
- **SYS-\* / CI-CD-\* / DOC-\*:** Kiểm thử hiệu năng/môi trường, static analysis (`npm run lint`), Docker Compose và CI/CD Pipeline

## 4. Rà soát tính nhất quán (Consistency check)

1. **Tính nhất quán về thực thể dữ liệu:** `Class-01` (`docs/diagrams/class-domain.puml` & `docs/diagrams/class-domain.md`) đồng bộ 100% với `apps/api/prisma/schema.prisma`, bao gồm đủ 12 model (`Category`, `Product`, `User`, `Order`, `OrderItem`, `Payment`, `Voucher`, `LoyaltyTransaction`, `Ingredient`, `RecipeItem`, `RefundRequest`, `IngredientAuditLog`) và 9 enum (`Role`, `Size`, `OrderStatus`, `PaymentMethod`, `PaymentStatus`, `DiscountType`, `TransactionType`, `RefundRequestStatus`, `IngredientLogAction`).
2. **Tính nhất quán về trạng thái & cửa sổ thanh toán:** Order State Machine trong SRS, `ADR-003`, `use-case-checkout.md`, `Activity-01`, `Sequence-01` và `order-state-machine.ts` thống nhất 7 trạng thái chuẩn (`PENDING`, `PAID`, `PREPARING`, `READY`, `COMPLETED`, `PAYMENT_FAILED`, `CANCELLED`) cùng cửa sổ thanh toán 10 phút (`ORDER_PAYMENT_WINDOW_MS`, `OrderExpirationService`).
3. **Tính nhất quán về tham số nghiệp vụ & kiểm thử:** Header `Idempotency-Key`, optimistic locking (`Product.version`), khấu trừ nguyên liệu (`RecipeItem`), và phân tách `PAYMENT_PROVIDER` (`MOCK`/`VNPAY`) được phủ đầy đủ bởi 17 FRs, 20 NFRs, 24 Jest suites backend (326 tests), 28 test thanh toán frontend (`apps/web/tests/vnpay-payment.test.mjs`), E2E (`app.e2e-spec.ts`, `tests/e2e-checkout.flow.mjs`, `tests/e2e-integration.spec.ts`) và CI/CD trên Node 24.
